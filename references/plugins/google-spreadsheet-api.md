## Interpretation

The current installed object set looks like a **generic Google credentials dependency package**, not a functional Spreadsheet API plugin.

Possible explanations:

1. The plugin package is incomplete and missing its Spreadsheet action/API definitions.
2. The installed package is actually an auth/config dependency that has been mislabeled as `Google Spreadsheet API`.
3. Spreadsheet actions are expected to be generated by another dependent plugin, but that dependency relationship is not obvious from the installed application objects.
4. MCP may not expose some rendered UI-level plugin package metadata, but MCP does expose actions/schemas/APIs/jobs; no Spreadsheet operational objects were returned.
